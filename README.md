# Football-ai-project

This project uses machine learning to predict football match results and analyze player statistics.

---

## 🔥 Features
- Match prediction (Home / Away / Draw)
- Player stats search
- Top assist analysis
- Data visualization using Matplotlib

---

## 🧠 Tech Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

---

## 📊 How to Use
Run the notebook and type commands like:

- predict PSG vs Arsenal  
- player Messi  
- assists  

---

## 📁 Dataset
- Champions League match dataset  
- Player attacking stats dataset
